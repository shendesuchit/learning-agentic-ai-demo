# LangChain — Introduction

## What is LangChain?

LangChain is a framework intended to help developers build applications around language models and related components.

## Why do frameworks exist?

A framework can provide reusable abstractions so developers do not have to build every integration and execution pattern from scratch.

message = "Explain middleware simply."

## My takeaway

> A framework gives structure around common application-building patterns.
